# AutoDrive — Car Dealership Web Application

A responsive car dealership web application developed with React and Vite as my final frontend course project.

## Technologies

- React
- JavaScript (ES6+)
- HTML
- CSS
- Git & GitHub
- Netlify
- Bootstrap

## Features

- Car catalog
- Filtering cars by fuel type
- Individual car pages
- Responsive design for desktop, tablet and mobile
- Interactive image gallery
- Purchase request form with validation
- Test drive request form with validation
- Navigation with React Router

## About the Project

This project demonstrates my practical frontend development skills, including working with React components, routing, forms, responsive layouts and interactive user interfaces.
